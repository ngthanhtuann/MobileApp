# Bài tập Lập trình thiết bị di động

## Cấu trúc

```
week1/
├── ui_student/      # Dự án Flutter: giao diện hồ sơ sinh viên
```

## Chạy ứng dụng tuần 1

```bash
cd week1/ui_student
flutter pub get
```
