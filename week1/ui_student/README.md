# Bài tập 1 — UI hồ sơ sinh viên

Ứng dụng dựng màn hình hồ sơ sinh viên gồm avatar, họ tên và mã số sinh viên.

## Chạy

Mở terminal tại thư mục `week1/ui_student` rồi chạy:

```bash
flutter pub get
flutter run
```

Chọn thiết bị Android đã kết nối hoặc chạy trên Chrome bằng `flutter run -d chrome`.

## Tệp chính

- `lib/main.dart`: giao diện hồ sơ sinh viên.
- `pubspec.yaml`: cấu hình và dependencies Flutter.
- `android/`, `web/`: cấu hình để chạy ứng dụng trên Android và Web.
